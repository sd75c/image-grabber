产品介绍

商品图散落在页面各处，整理一次要花很久

主图在轮播里，缩略图带着 CDN 尺寸后缀，详情长图藏在懒加载容器中。逐张右键另存不仅容易漏图，还可能把低清缩略图当成原图保存下来。

  • 主图、缩略图、详情图分散在不同容器，需要逐段翻找
  • 同一张图的缩略图与原图混在一起，重复保存
  • JPEG、WebP、AVIF 格式不统一，后续处理还要再转格式

手动整理

费时且容易遗漏
  • ×30 张图要逐张右键、命名、归档
  • ×分不清缩略图与原图，保存后才发现模糊
  • ×图标、店铺 logo、二维码混进相册

核心功能

从扫描到落盘，一条顺畅的流水线

把提取、去重、预览、勾选和下载放在同一个流程里，不再在多个标签页之间来回切换。

一键提取

点击商品页右下角的悬浮按钮，扫描图片、srcset、懒加载属性和背景图，不用逐张翻找。

主图 · 缩略图 · 详情图

智能过滤

过滤小于面积与边长门槛的图标、占位图、二维码，并按站点 CDN 规则去掉重复的尺寸变体。

尺寸门槛 + URL 归并

集中预览

独立画廊用统一网格展示缩略图和真实像素尺寸，一眼判断哪张是原图、哪张是详情长图。

独立标签页画廊

自由勾选

点击卡片或复选框选择图片，支持全选与反选，已选数量实时更新，只下载真正需要的图片。

全选 · 反选 · 计数

PNG 格式

授权图片域名后，JPEG、WebP、AVIF 通过 Canvas 转为 PNG；GIF 与 SVG 则保留原格式。

可随时关闭转换

批量下载

按「站点 / 商品标题」自动建立下载目录，展示整体进度与单张状态，失败项可以再次下载。

进度反馈 · 失败重试

安装步骤

四步加载到 Chrome

扩展以「已解压」方式加载，不经过应用商店。整个过程不需要命令行或构建工具。

  1. 01

    下载并解压插件

    从下载区获取项目仓库的源码压缩包并解压到固定目录。解压后应能看到 manifest.json，以及 background.js、gallery.html 等文件；版本号以 manifest.json 为准。

  2. 02

    打开扩展管理页

    在 Chrome 地址栏输入下面的地址并回车。

    chrome://extensions
  3. 03

    开启开发者模式

    打开扩展管理页右上角的「开发者模式」开关，页面会显示「加载已解压的扩展程序」按钮。

  4. 04

    加载已解压的扩展程序

    点击「加载已解压的扩展程序」，选择第 1 步解压出、包含 manifest.json 的文件夹。安装后建议固定到工具栏，并刷新已经打开的商品页。

版本要求：Chrome 102 或更高版本（扩展使用 storage.session）。Edge 等 Chromium 浏览器可用相同方式加载。扩展只在淘宝、天猫、京东、拼多多的商品详情页注入悬浮按钮，其他页面不受影响。
